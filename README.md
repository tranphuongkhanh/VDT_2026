# VDT_2026
Hệ thống quản lý quy trình phê duyệt nội bộ

## Mô tả
Xây dựng nền tảng cho phép người dùng tạo và xử lý các quy trình phê duyệt như nghỉ phép, mua sắm, tạm ứng, thanh toán, đề xuất tuyển dụng. Người dùng gửi yêu cầu, hệ thống tự động chuyển qua các cấp duyệt theo workflow cấu hình sẵn.

## Các chức năng chính:
* Đăng nhập và phân quyền người dùng
* Quản lý phòng ban và cơ cấu tổ chức
* Quản lý loại yêu cầu phê duyệt
* Quản lý biểu mẫu yêu cầu
* Cấu hình workflow phê duyệt
* Tạo,duyệt, từ chối và xử lý yêu cầu
* Quản lý file đính kèm
* Dashboard và báo cáo

## Công nghệ sử dụng: 
Java Spring, ReactJs, PostgreSQL
